# Minecraft-style viewer assets

The shared search/sidebar frame texture is from [Mojang's Bedrock samples](https://github.com/Mojang/bedrock-samples/tree/main/resource_pack/textures/ui). The earlier Bedrock page/arrow textures have been removed; the active book uses the original Checklist sprite sheet documented in `../checklist/ATTRIBUTION.md`. Texture copyright belongs to Mojang/Microsoft; the samples repository's license and Minecraft usage guidelines apply. This is an unofficial fan viewer.

The Minecraft-style OpenType font is by [Idrees Hassan](https://github.com/IdreesInc/Minecraft-Font), licensed under the SIL Open Font License 1.1. See `FONT-LICENSE.txt`. It is a fan-made recreation, not an original Minecraft font file.

All assets are served locally; the reader requires no third-party font or image requests.

The dirt background is the original 16 × 16 [dirt block texture](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/textures/blocks/dirt.png) from the same Mojang Bedrock samples repository. The viewer tiles it locally with a dark CSS overlay.
